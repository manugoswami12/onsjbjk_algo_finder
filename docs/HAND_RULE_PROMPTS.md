# Hand-rule prompts (TheAlgorithms/Python, doc 04 section 17)

Run these prompts in future to write rules by hand: for most labels one or two relations will work. Each label below was not learned (T1 own file, T2 no other file claims it, T3 held-out Rosetta files). Generated by `eval_ta.py --status`; the full prompt of every label is one line of `benchmark/hand_rule_prompts.jsonl`.

## Prompt per failure kind

Two ways to write the rule: a general relation (the prompts per kind below: the same component in every language, with an own positive and a close negative), or a file rule that only identifies the corpus file (the file-rule prompt; each label has both in the JSONL).

### file rule

> Write a file rule for <label> (<files>) in prolog/ta_file_rules.pl. Run `python ta_distinct.py CORPUS --propose <label>`: it lists the components (a statement's relation or call, names abstracted, parameters by position) that no file of another label has, or a pair of them, or one with exclusions (\+ has_rel(_, C) for a component of each other file that has it). Keep the component that is the algorithm's own logic on its inputs (not input reading, printing or a test), write `hand_specific(F, '<label>') :- has_rel(F, ...)` with a comment naming the component in words, and check: `eval_ta.py CORPUS --rehand --dir <folder>` then `--status` (T1: its files are answered <label>; T2: no other file is). One clause per file group usually does it.

### no_logic (2 labels)

> The logic of {files} is not traced: no tree node and no runnable behaviour. Dump its facts (prolog/tree_main.pl via learn_facts.tree_facts) and find the component the lowering drops or the tree has no branch for. If a front end drops it, extend the v0.2 subclass (imperative_logic.py, haskell_logic.py) so the same component gives the same term in every language; else add one family path in prolog/families_v02.pl for the component that makes it {label}. Add an own Python positive, an own program in another language and a close negative to tests/test_uniform.py. Rerun `eval_ta.py CORPUS --run --dir {folder}` and `--status`; keep the rule only if no other label loses (T2) and the staged run (eval_learn.py --stage 101) does not drop.
