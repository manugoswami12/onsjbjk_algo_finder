# Rule prompts: one per rule written (doc 04 section 17.5)

Run a prompt to write the same kind of rule for a new file. `benchmark/rule_prompts.jsonl` has every entry with its full prompt and the clauses it produced; generated by `python ta_prompts.py CORPUS`.

- file rules (identify one corpus file): 503 labels
- general relations (the same component in every language): 51 labels

## The two prompts

> Identify {files} as {label}. Run `python ta_distinct.py CORPUS --propose {label}` and keep the component that is the algorithm's own logic on its inputs: {component}. Write it as `hand_specific(_, '{label}') :- file_has(...)` in prolog/ta_file_rules.pl (or add {label} to benchmark/ta_file_rule_labels.json and run --write). Check with `eval_ta.py CORPUS --rehand --dir {folder}` and `--status`: every file of {label} answered {label} (T1), no other file answered {label} (T2).

> Write a general relation for {label} in prolog/ta_rules.pl, the same in every language: `hand_branch(Node, F, {label})` over the language-neutral facts (exchange/4, loops, under/2, loop_step/2, value/3, guards). Test it on an own Python program, an own program in another language and a close negative (tests/test_uniform.py HandRuleTests), then over the corpus (no new T2 claims) and the Rosetta files of its task (T3).
